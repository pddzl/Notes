
## 指标

| 指标类型 | 告警类型 | 说明          |
| ---- | ---- | ----------- |
| 生死指标 | 灾难告警 | 服务中断、业务不可用  |
| 关键指标 | 严重告警 | 业务受影响或即将受影响 |
| 辅助指标 | 一般告警 | 风险提示、排障辅助   |

## 事件等级


| 对象       | 指标      | 告警等级 | 事件等级 |
| -------- | ------- | ---- | ---- |
| 核心MES数据库 | DB Down | 灾难   | P1   |
| 测试数据库    | DB Down | 灾难   | P3   |
