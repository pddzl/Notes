### Name

| Name                        | Example                       | Common usage                             |
| --------------------------- | ----------------------------- | ---------------------------------------- |
| camelCase                   | `userName`, `getUserById`     | JavaScript, Go variables/functions, Java |
| PascalCase / UpperCamelCase | `UserName`, `GetUserByID`     | Go exported names, classes/types         |
| snake_case                  | `user_name`, `get_user_by_id` | Python, SQL, databases                   |
| kebab-case                  | `user-name`, `get-user-by-id` | URLs, CSS, filenames, CLI options        |
| UPPER_SNAKE_CASE            | `MAX_RETRY_COUNT`             | Constants, environment variables         |
| lowercase                   | `username`, `userid`          | Simple names, some config keys           |
| dot.case                    | `user.name`, `server.port`    | Configuration/property keys              |
| Pascal_Snake_Case           | `User_Name`                   | Relatively uncommon                      |
