## 核心含义

`as` 表示"作为、当作"，把某人或某物放在某种**身份、角色或用途**之下

具体关系由上下文决定。

## 作为某种角色 / 身份

表示某人以某种身份、职业或角色出现

结构

```text
人 + as + 身份 / 职业 / 角色
```

位置：一般在句首或句尾，动词之后或被修饰的名词之后

例子

```text
I work as an engineer in a tech company.
我在一家技术公司里做工程师

As a teacher, she cares a lot about her students.
作为一名老师，她非常关心学生

He became famous as a writer.
他作为作家而出名
```

## 把某物用作某物

表示把某个东西当作某种用途来使用

结构

```text
use / 把 A as B
```

例子

```text
He used a leaf as a bookmark.
他把一片叶子作为书签

We use this room as a meeting room.
我们把这个房间用作会议室

English is used as a working language in many companies.
英语在许多公司里被用作工作语言
```

## 被视为 / 被看作

表示把某人或某物评价、描述成某种样子

常与 regard / see / think of / describe 等动词搭配

结构

```text
动词 + 宾语 + as + 名词 / 形容词
```

例子

```text
I regard him as my best friend.
我把他视为我最好的朋友

People see her as a natural leader.
人们把她看作天生的领导者

They described the plan as risky.
他们认为这个计划有风险
```

## 常见搭配

- `work as ...` — 从事...工作
- `serve as ...` — 充当...；起...作用
- `use A as B` — 把A用作B
- `be known as ...` — 作为...而闻名
- `regard A as B` — 把A看作B
- `see A as B` — 把A视为B
- `think of A as B` — 把A当作B

## 与 `like` 的区别

`as` 和 `like` 都可以表示"像..."

- as → 强调**事实上的身份或角色**，A 确实是 B
- like → 强调**相似**，A 不是 B，只是像 B

```text
He works as a manager.
他是经理（事实身份）

He works like a manager.
他干活像个经理（并非经理）
```

## 总结

`as` 常见的核心用法：

| 用法      | 核心意思    | 例子                       |
| ------- | ------- | ------------------------ |
| 角色 / 身份 | 作为...   | work as an engineer      |
| 用途      | 被用作...  | use a leaf as a bookmark |
| 看法 / 评价 | 把...看作  | regard him as a friend   |

**最重要的理解**

不要把：

> as = 像

当成唯一规则

更好的理解是：

> A as B → A 以 B 的身份存在，或 A 被当作 B 使用
