**虚词**和**实词**的区别，本质上看一个问题：

> **这个词有没有独立的实际意义？**

---

# 实词（Content Words）

实词有明确的词汇意义，即使单独拿出来，你也知道它表示什么。

例如：

|词类|例子|意义|
|---|---|---|
|名词|book|书|
|动词|run|跑|
|形容词|beautiful|美丽的|
|副词|quickly|快速地|

单独看：

- book → 一本书
- run → 跑
- beautiful → 美丽
- quickly → 快速地

你马上能想到具体意思。

因此这些叫：

```
实词 = 有实际意义的词
```

---

# 虚词（Function Words）

虚词本身意义很弱。

主要作用：

```
帮助表达语法关系
```

例如：

### 冠词

the

单独问：

> the 是什么意思？

很难翻译。

它只是告诉你：

```
这个名词是特指的
```

例如：

- a book（一本文书）
- the book（那本书）

---

### 介词

in

单独翻译：

```
在……里面
```

似乎有意思。

但实际上：

- in the room
- in 2025
- in danger
- in English

每次意思都不同。

它主要表示关系。

---

### 连词

and

单独看：

```
和
```

但它真正作用是：

```
连接
```

例如：

- Tom and Jerry

---

# 一个简单判断方法

看看这个词能不能作为一句话的核心内容。

例如：

```
dog
eat
beautiful
quickly
```

你能大致知道：

```
狗
吃
漂亮
快速地
```

这些是实词。

---

再看：

```
the
a
an
and
but
if
of
in
on
```

单独拿出来几乎无法表达完整意思。

这些是虚词。

PS:

如果按照英语学习的重要程度排序，建议：

**动词 → 名词 → 代词 → 形容词 → 副词 → 介词 → 连词 → 冠词 → 数词**

因为英语语法中约 **70% 的难点都集中在动词系统（时态、语态、情态、非谓语）**。掌握动词后，再学句法（五大句型、从句、特殊句式）会轻松很多。
