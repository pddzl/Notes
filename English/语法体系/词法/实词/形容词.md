### 作用

修饰人和物
### 位置

一般位于被修饰的人和物前
### 常见词尾

-al, -ive, -ary, -ful
### 例子

`critical period`, `creative idea`, `revolutionary`, `technological`, `careful person`

### 比较级&最高级

|        | 比较级                     | 最高级                        |
| ------ | ----------------------- | -------------------------- |
| 含义     | 更......                 | 最......                    |
| 句式结构   | A + 动词 + 比较级 + than + B | 主语 + 动词 + the + 最高级 + 比较范围 |
|        | A + 动词 + 比较级            | 主语 + 动词 + the + 最高级        |
| 常见变形规则 | 形容词/副词词尾 + er           | 形容词/副词词尾 + est             |
|        | more + 形容词/副词原形         | the most + 形容词/副词原形        |
|        | 不规则变形                   | 不规则变形                      |
