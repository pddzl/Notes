
Passive Voice
## 含义

**被动语态**表示主语是动作的**承受者**，即：

> **某人 / 某物被怎么样了。**

主动语态强调：

> **谁做了什么**

被动语态强调：

> **谁 / 什么被怎么样了**

### 对比

主动：

```text
My cat broke all of my model cars.
```

我的猫弄坏了我所有的汽车模型。

被动：

```text
All of my model cars were broken.
```

我所有的汽车模型都被弄坏了。

# 被动语态的常见用法

## 用法 1：动作的发出者未知

当不知道是谁做了这个动作时，可以使用被动语态。

```text
My car was stolen.
```

我的车被偷了。

这里不知道：

> 谁偷了车。

所以不需要说明动作发出者。

## 用法 2：强调动作的接受者

当我们更想强调**动作的接受者**时，可以使用被动语态。

```text
All of my model cars were broken!
```

我所有的汽车模型都被弄坏了！

如果想进一步说明是谁做的，可以在句尾加入：

> **by + 动作发出者**

```text
All of my model cars were broken by my cat!
```

我所有的汽车模型都被我的猫弄坏了！

### by + 动作发出者

```text
by + 人 / 事物
```

用于说明：

> **动作是谁做的。**

例如：

```text
The window was broken by Tom.
```

窗户被 Tom 打破了。

# 被动语态的基本结构

> **be + 过去分词**

其中：

- `be` 根据**时态和主语**发生变化
- 过去分词（Past Participle）表示被动

例如：

```text
is spoken
was built
are used
were broken
```

# 一般现在时的被动语态

## 含义

表示某人 / 某物**现在被怎么样**，通常表示：

- 客观事实
- 普遍情况
- 经常发生的事情

## 结构

> **am/is/are + 过去分词**

例如：

```text
English and French are spoken in many parts of the world.
```

世界上许多地方都使用英语和法语。

```text
Breakfast is served from 6 a.m. to 10 a.m. every day.
```

早餐每天早上 6 点到 10 点供应。

# 一般过去时的被动语态

## 含义

表示某人 / 某物在**过去被怎么样了**。

## 结构

> **was/were + 过去分词**

例如：

```text
The window was broken yesterday.
```

窗户昨天被打破了。

```text
The cars were repaired last week.
```

这些汽车上周被修好了。

# 现在进行时的被动语态

## 含义

表示某人 / 某物**现在正在被怎么样**。

## 结构

> **am/is/are + being + 过去分词**

这里的 `being` 表示：

> **正在进行**

例如：

```text
The road is being repaired.
```

这条路正在被维修。

```text
The building is being constructed.
```

这栋建筑正在被建造。

# 过去进行时的被动语态

## 含义

表示某人 / 某物在**过去某个时间正在被怎么样**。

## 结构

> **was/were + being + 过去分词**

例如：

```text
That road was being built when we visited here last time.
```

我们上次来这里的时候，那条路正在被修建。

这里：

```text
was being built
```

可以拆成：

```text
was       → 过去
being     → 正在进行
built     → 被动
```

# 情态动词 + 被动语态

情态动词可以和被动语态连用。

## 基本结构

> **情态动词 + be + 过去分词**

例如：

```text
can be
must be
should be
may be
might be
could be
would be
```

### 例句

```text
The building can be accessed by employees during working hours only.
```

员工只能在工作时间进入这栋大楼。

这里：

```text
can be accessed
```

可以拆成：

```text
can       → 情态
be        → 被动结构
accessed  → 过去分词
```

## must + 被动语态

```text
You must be shocked, too.
```

你一定也很震惊。

这里需要注意：

> `must be shocked` 中的 `must` 表示**有把握的推测**。

结构：

```text
must + be + 过去分词
```

即：

> **一定是被……**

# 不同时态的被动语态

| 时态 | 被动语态结构 | 例子 |
|---|---|---|
| 一般现在时 | `am/is/are + 过去分词` | The room is cleaned. |
| 一般过去时 | `was/were + 过去分词` | The room was cleaned. |
| 现在进行时 | `am/is/are + being + 过去分词` | The room is being cleaned. |
| 过去进行时 | `was/were + being + 过去分词` | The room was being cleaned. |
| 情态动词 | `情态动词 + be + 过去分词` | The room can be cleaned. |

# 被动语态的核心规律

无论是什么时态，被动语态的核心都是：

> **be + 过去分词**

变化的主要是 `be`。

```text
一般现在时
am/is/are + done

一般过去时
was/were + done

现在进行时
am/is/are + being + done

过去进行时
was/were + being + done

情态动词
can/must/should + be + done
```

因此可以把被动语态理解成：

> **时态主要体现在 be 上，动作本身使用过去分词。**

# 主动语态 vs. 被动语态

### 主动语态

> 主语是动作的发出者。

```text
The cat broke the window.
```

猫打破了窗户。

结构：

```text
动作发出者 + 动词 + 动作接受者
```

### 被动语态

> 主语是动作的接受者。

```text
The window was broken by the cat.
```

窗户被猫打破了。

结构：

```text
动作接受者 + be + 过去分词 + by + 动作发出者
```

# 一句话总结

> **被动语态 = 主语是动作的接受者。**

核心结构：

> **be + 过去分词**

如果需要说明动作是谁做的：

> **by + 动作发出者**

最重要的几个结构：

```text
一般现在时：
am/is/are + 过去分词

一般过去时：
was/were + 过去分词

现在进行时：
am/is/are + being + 过去分词

过去进行时：
was/were + being + 过去分词

情态动词：
情态动词 + be + 过去分词
```
