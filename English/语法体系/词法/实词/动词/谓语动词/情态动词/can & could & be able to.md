
`can`、`could` 和 `be able to` 都可以表示**能力**。

核心含义：

> **can / could / be able to = 能够、会**

但三者在**时态、具体场景和语气**上有所不同。

## 1. can：表示现在的能力

### 形式

**主语 + can + 动词原形**

```text
I can swim.
```

我会游泳。

```text
She can speak English.
```

她会说英语。

这里的 `can` 表示：

> **现在具有某种能力。**

## 2. could：表示过去的能力

### 形式

**主语 + could + 动词原形**

```text
I could swim when I was five.
```

我五岁的时候就会游泳。

```text
She could speak English when she was young.
```

她年轻的时候会说英语。

这里：

> `could` 是 `can` 的过去形式。

```text
现在：can
过去：could
```

## 3. be able to：表示能够

### 形式

**be able to + 动词原形**

```text
I am able to swim.
```

我能够游泳。

```text
She is able to solve the problem.
```

她能够解决这个问题。

`be able to` 和 `can` 在表示一般能力时通常可以互换：

```text
I can swim.
```

```text
I am able to swim.
```

两者都表示：

> 我会游泳 / 我能够游泳。

不过：

> **can 更常用、更自然。**

# can vs. be able to

## 一般能力

表示某人具有某种能力时，通常优先使用 `can`。

```text
I can drive.
```

我会开车。

比：

```text
I am able to drive.
```

更自然。

## 为什么还需要 be able to？

因为 `can` 本身的形式比较有限。

`can` 没有完整的时态变化：

```text
can
could
```

但是 `be able to` 可以随着 `be` 变化。

例如：

### 现在

```text
I am able to help you.
```

### 过去

```text
I was able to help you.
```

### 将来

```text
I will be able to help you.
```

### 现在完成时

```text
I have been able to help you.
```

因此：

> **当需要表达 can 没有的时态时，可以使用 be able to。**

# 4. 表示将来的能力

不能直接使用 `can` 表示普通的将来能力。

通常使用：

> **will be able to + 动词原形**

```text
I will be able to drive next year.
```

我明年就能够开车了。

```text
She will be able to join us tomorrow.
```

她明天就能够加入我们。

# 5. 表示过去某一次成功做到某事

这是 `could` 和 `was/were able to` 一个非常重要的区别。

### 一般过去某一次成功完成

通常使用：

> **was/were able to + 动词原形**

```text
I was able to fix the computer yesterday.
```

我昨天成功修好了电脑。

这里强调：

> **昨天这一次，我最终成功做到了。**

### could

`could` 更常用于表示：

> **过去的一般能力**

```text
When I was young, I could run very fast.
```

我年轻的时候能跑得很快。

这里不是某一次具体事件，而是过去具有这种能力。

## 对比

### 过去的一般能力

```text
When I was young, I could swim.
```

我年轻的时候会游泳。

> 强调过去具有游泳的能力。

### 某一次成功做到

```text
Yesterday, I was able to swim across the river.
```

昨天我成功游过了那条河。

> 强调昨天这一次最终成功完成。

# 6. 否定形式

## can not / can't

**can't + 动词原形**

```text
I can't swim.
```

我不会游泳。

## could not / couldn't

**couldn't + 动词原形**

```text
I couldn't swim when I was young.
```

我年轻的时候不会游泳。

## be unable to

`be able to` 的否定形式：

> **be unable to + 动词原形**

```text
I am unable to help you.
```

我无法帮助你。

不过日常英语中通常更自然地说：

```text
I can't help you.
```

# 7. 三者的核心区别

| | can | could | be able to |
|---|---|---|---|
| 现在能力 | ✅ | ❌ | ✅ |
| 过去一般能力 | ❌ | ✅ | ✅ |
| 将来能力 | ❌ | ❌ | ✅ |
| 某次成功做到 | 一般现在场景 | 有时可以 | **✅ 常用** |
| 后面 | 动词原形 | 动词原形 | 动词原形 |
| 日常使用 | **非常常用** | **非常常用** | 比较正式 / 用于需要其他时态的情况 |

# 8. 结构总结

### can

```text
can + 动词原形
```

```text
I can swim.
```

### could

```text
could + 动词原形
```

```text
I could swim.
```

### be able to

```text
be able to + 动词原形
```

根据时态改变 `be`：

```text
am/is/are able to
was/were able to
will be able to
have/has been able to
```

---

# 一句话总结

> **can = 现在能**
>
> **could = 过去能 / 更委婉的“能”**
>
> **be able to = 能够，可以根据需要改变时态**

最重要的区别：

```text
现在能力：
I can swim.

过去一般能力：
I could swim.

将来能力：
I will be able to swim.

过去某一次成功做到：
I was able to swim across the river.
```
