动词 -ing形式与过去分词作修饰语

动词的 **-ing 形式**和**过去分词**都可以用来修饰名词。

> **-ing 形式通常表示主动、进行或持续状态**
>
> **过去分词通常表示被动、完成或结果状态**

## 1. ing形式作修饰语

### 1.1 修饰人或物

结构：

> **doing + 名词**

通常表示：

- 主动发出动作
- 动作正在进行
- 持续的状态

例如：

```text
the crying baby
```

正在哭的婴儿

```text
the running water
```

流动的水

```text
the shining star
```

闪耀的星星

可以把它理解成：

```text
the crying baby
↓
the baby is crying
```

```text
the running water
↓
the water is running
```

## 2. 过去分词作修饰语

### 2.1 修饰人或物

结构：

> **过去分词 + 名词**

通常表示：

- 被动关系
    
- 动作已经完成
    
- 动作产生的结果或状态

例如：

```text
the broken window
```

被打破的窗户

```text
the written report
```

写好的报告

```text
the used car
```

用过的汽车 / 二手车

可以把它理解成：

```text
the broken window
↓
the window was broken
```

```text
the written report
↓
the report was written
```

## 3. -ing 和过去分词的区别

|形式|核心关系|例子|
|---|---|---|
|**-ing**|主动 / 进行 / 持续状态|the crying baby|
|**过去分词**|被动 / 完成 / 结果状态|the broken window|

### 对比

```text
the crying baby
```

> baby 主动发出 `cry` 这个动作

```text
the broken window
```

> window 承受 `break` 这个动作

# 4. -ing 分词短语

-ing 形式不仅可以放在名词前修饰名词，也可以形成**分词短语**，对句子的主语进行补充说明。

常见含义：

- 时间
    
- 原因
    
- 伴随情况
    
- 条件等

### 例子

```text
Looking at the phone, Max found that it was almost 12 o'clock.
```

看着手机，Max 发现已经快 12 点了。

这里：

```text
Looking at the phone
```

是 **-ing 分词短语**。

它说明：

> Max 在看手机的时候……

可以理解为：

```text
When Max was looking at the phone,
Max found that it was almost 12 o'clock.
```

## 表示原因

```text
Feeling tired, I went to bed early.
```

因为感到疲惫，我早早上床睡觉了。

可以理解为：

```text
Because I felt tired, I went to bed early.
```

# 5. 过去分词短语

过去分词也可以形成**分词短语**，对句子的主语进行补充说明。

通常表示：

- 被动
    
- 已完成
    
- 结果状态

### 例子

```text
Baked in the oven for an hour, the bread became like this.
```

面包在烤箱里烤了一个小时后，变成了这样。

这里：

```text
Baked in the oven for an hour
```

是**过去分词短语**。

可以理解为：

```text
After the bread was baked in the oven for an hour,
the bread became like this.
```

# 6. 动名词和 -ing 分词

虽然动名词和 -ing 分词都是：

> **动词 + -ing**

但它们在句子中的作用不同。

## 动名词

动名词在句子中**起名词作用**。

```text
Swimming is good for your health.
```

游泳对你的健康有好处。

这里：

```text
Swimming
```

作主语。

所以是：

> **动名词**

## -ing 分词作修饰语

```text
The swimming boy is my brother.
```

那个正在游泳的男孩是我的弟弟。

这里：

```text
swimming
```

修饰：

```text
boy
```

所以是：

> **-ing 分词作修饰语**

# 7. -ing 形式的常见身份

看到 `doing` 时，不能仅仅根据 `-ing` 判断它是动名词。

需要看它在句子中的作用。

|用法|例句|作用|
|---|---|---|
|**动名词**|Swimming is fun.|作名词|
|**-ing 分词**|The swimming boy is Tom.|修饰名词|
|**进行时**|Tom is swimming.|与 be 构成进行时|

# 8. 核心总结

## -ing 形式修饰名词

> **doing + 名词**

通常表示：

> **主动 / 正在进行 / 持续状态**

```text
the crying baby
the running water
the shining star
```

## 过去分词修饰名词

> **过去分词 + 名词**

通常表示：

> **被动 / 完成 / 结果状态**

```text
the broken window
the written report
the used car
```

## -ing 分词短语

> **doing ..., 主句**

通常表示：

> **时间、原因、伴随情况等**

```text
Looking at the phone, Max found that it was almost 12 o'clock.
```

## 过去分词短语

> **过去分词 ..., 主句**

通常表示：

> **被动、完成或结果状态**

```text
Baked in the oven for an hour, the bread became like this.
```

# 9. 最重要的区别

> **动名词、-ing 分词和过去分词不能只看形式判断，要看它在句子中发挥什么作用。**

```text
Swimming is fun.
↓
作名词
→ 动名词
```

```text
The swimming boy is Tom.
↓
修饰名词
→ -ing 分词
```

```text
Tom is swimming.
↓
与 be 构成进行时
→ 现在进行时
```

```text
The broken window is expensive to replace.
↓
修饰名词
→ 过去分词
```
