
英语句子主要由 **五大基本句型** 构成，此外还有一种常见的特殊句型 **There be**。

## 主谓（SV）

### 构成

**主语 + 谓语**

- **主语（Subject）**：动作的发出者或句子描述的对象。
    
- **谓语（Verb）**：表示动作或状态。
### 特点

谓语动词为**不及物动词**，后面**不需要宾语**。
### 例句

```text
 I run.（我跑步。）
 Birds fly.（鸟会飞。）
 He smiled.（他笑了。）
```

## 主谓宾（SVO）

### 构成

**主语 + 谓语 + 宾语**

- **主语（Subject）**：动作的发出者。
    
- **谓语（Verb）**：表示动作。
    
- **宾语（Object）**：动作涉及或作用的对象。
### 特点

谓语通常为**及物动词**，后面必须有宾语。

### 例句

```text
We study English.
She reads books.
They built a house.
```

## 主系表（SVC）

### 构成

**主语 + 系动词 + 表语**

### 系动词

#### 1. Be 动词

`am`, `is`, `are`, `was`, `were`
#### 2. 感官系动词

`look`, `sound`, `smell`, `feel`, `taste`
#### 3. 常见系动词

`become`,`seem`, `remain`, `appear`, `stay`, `turn`, `grow`
### 表语

用于**说明主语的身份、性质、状态或特征**。

### 例句

```text
My mom is a teacher.
The dress looks beautiful.
The soup tastes delicious.
He became a doctor.
```

## 主谓双宾（SVOO）

### 构成

#### 形式一

**主语 + 谓语 + 间接宾语（人） + 直接宾语（物）**

#### 形式二

**主语 + 谓语 + 直接宾语（物） + to/for + 间接宾语（人）**

### 注意

不是所有动词都可以接双宾。

常见双宾动词包括：

`give`, `bring`, `send`, `tell`, `show`, `pass`, `lend`, `write`, `buy`, `make`

其中：

- **to**：表示"把某物给某人"（give、send、lend、pass……）
    
- **for**：表示"为某人做某事"（buy、make……）
### 例句

```text
I wrote John an email.
I lent the computer to my sister.
I bought a computer for my sister.
She gave me a gift.
```

## 主谓宾补（SVOC）

### 构成

**主语 + 谓语 + 宾语 + 宾语补足语**

### 宾语补足语

用于**补充说明宾语的状态、身份、特征或动作结果**。

### 注意

- 宾补必须位于宾语之后。
    
- 宾补与宾语之间存在逻辑上的"主谓"或"主系表"关系。

常见动词：

`make`, `get`, `keep`, `find`, `paint`, `call`, `elect`, `name`

### 例句

```text
The news got me excited.
Fun stories make me happy.
We painted the wall white.
They elected him president.
```

## 特殊句型：There be

### 构成

**There + be + 某人 / 某物 / 某事**

### 含义

表示：

- 某地**存在**某人或某物；
    
- 某事**发生**。

### 注意

- **be** 的形式由后面的名词决定。
    
- There be 表示"存在"，不能表示"拥有（have）"。

### 例句

```text
There is a cat.
There are two students.
There is an accident.
There will be a meeting tomorrow.
```

# 总结

|句型|构成|核心特点|
|:--|:--|:--|
|主谓（SV）|主语 + 谓语|不及物动词，无宾语|
|主谓宾（SVO）|主语 + 谓语 + 宾语|及物动词，必须有宾语|
|主系表（SVC）|主语 + 系动词 + 表语|表语说明主语|
|主谓双宾（SVOO）|主语 + 谓语 + 间接宾语 + 直接宾语|有两个宾语（人 + 物）|
|主谓宾补（SVOC）|主语 + 谓语 + 宾语 + 宾补|宾补说明宾语|
|There be|There + be + 名词|表示某人、某物或某事存在|

> **SV 看动作；SVO 看对象；SVC 看状态；SVOO 给两样；SVOC 补宾语；There be 表存在。**
