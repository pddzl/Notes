# 三大结构

英语句子从结构上可以分为三大类：

| 类型  | 英文                | 核心结构        |
| --- | ----------------- | ----------- |
| 简单句 | Simple Sentence   | 一个独立分句      |
| 并列句 | Compound Sentence | 独立分句 + 独立分句 |
| 复合句 | Complex Sentence  | 主句 + 从句     |

## 什么是复合句

> 复合句由一个独立分句（主句）+ 一个或多个从属分句（从句）组成。

```text
主句 + 从句
```

从句不能独立表达完整意思，必须依附于主句。

### 例句拆解

```text
I stayed home because it was raining.
└── 主句 ──┘ └──── 从句 ────┘
```

| 部分 | 能否独立成句 |
|------|------------|
| `I stayed home` | ✅ 可以独立成句 |
| `because it was raining` | ❌ 不能单独作为完整句子 |


## 三大结构对比

| 类型  | 核心结构        | 例句                                        |
| --- | ----------- | ----------------------------------------- |
| 简单句 | 一个独立分句      | I stayed home.                            |
| 并列句 | 独立分句 + 独立分句 | I stayed home, **and** she went out.      |
| 复合句 | 主句 + 从句     | I stayed home **because** it was raining. |

## 判断方法

遇到一个长句子，只需问一句：

> **有几个"可以独立成句"的部分？**

-> 只有一个独立分句 → 简单句

```text
I stayed home.
```

-> 有两个独立分句 → 并列句

```text
I stayed home, and she went out.
```

拆开后两部分都能独立成句：

```text
I stayed home.    ✔
She went out.     ✔
```

-> 一个独立分句 + 一个不能独立成句的部分 → 复合句

```text
I stayed home because it was raining.
```

拆分验证：

```text
I stayed home.            ✔ 可以独立
Because it was raining.   ✘ 不能独立表达完整意思
```

## 一图速记

```text
简单句 ──→ 一个完整句子
            I stayed home.

并列句 ──→ 两个完整句子并列
            I stayed home, and she went out.
            └──── 独立 ────┘   └──── 独立 ────┘

复合句 ──→ 主句 + 从句
            I stayed home because it was raining.
            └── 主句 ──┘ └──── 从句 ────┘
```

> 💡 **关键区别**：并列句的两个分句**地位平等**；复合句中的从句**依附于主句**，地位从属。

## 后续学习重点

复合句是英语长难句的核心，其中的从句主要分为三类：

| 从句类型  | 例句                                       | 作用                 |
| ----- | ---------------------------------------- | ------------------ |
| 名词性从句 | I know that he is right.                 | 从句充当主语/宾语/表语等名词性成分 |
| 定语从句  | The man who lives next door is a doctor. | 从句修饰限定名词           |
| 状语从句  | I stayed home because it was raining.    | 从句说明时间、原因、条件等      |

整体知识框架

```text
英语句子
├── 简单句
├── 并列句
└── 复合句
    ├── 名词性从句（主语从句 / 宾语从句 / 表语从句 / 同位语从句）
    ├── 定语从句
    └── 状语从句
```
