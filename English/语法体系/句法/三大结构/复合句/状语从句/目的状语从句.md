## 概念

Adverbial Clause of Purpose

> 说明某个动作或状态的意图、目的的从句，即"为了..."

## 结构

```text
主句 + 连接词 + 陈述句（目的）
```

常见连接词：

| 连接词           | 含义    | 语气              |
| ------------- | ----- | --------------- |
| so that       | 为了；以便 | 最常用，可接肯定/否定     |
| in order that | 为了    | 较正式，用法同 so that |
| in case       | 以防；万一 | 表示"预防某种情况"      |

例句拆解

```text
We need to get up at 4 o'clock so that we can catch the sunrise.
└────────── 主句 ──────────┘ └──── 目的从句 ────┘
为了赶上日出，我们需要 4 点起床。
```


## 使用要点

### 从句中常含情态动词

目的从句中常用 can / could / may / might / will / would 等情态动词：

```text
He studies hard so that he can pass the exam.
他努力学习，以便能通过考试。
```

### so that 既可表目的，也可表结果

| 类型  | 判断依据                       | 例句                                                           |
| --- | -------------------------- | ------------------------------------------------------------ |
| 目的  | 从句含情态动词（can/may等），表"打算做的事" | I got up early so that I could catch the first bus.（为了赶上首班车） |
| 结果  | 从句陈述既成事实，表"造成的结果"          | I got up late, so that I missed the first bus.（结果错过了首班车）     |

### in case 的特殊用法

```text
Take an umbrella in case it rains.
带把伞，以防下雨。
```

> 💡 in case 后接一般现在时表将来（不用 will），这是状语从句的普遍规则

## 目的 vs 结果：快速区分

```text
so that + can/may/will ...   →  目的（想做、将做）
so that + 陈述既成事实        →  结果（已发生）
```

```text
He whispered so that nobody could hear him.
他压低声音，为的是没人能听见。        ← 目的 ✅

He whispered, so that nobody heard him.
他压低了声音，结果没人听见他。        ← 结果 ✅
```
