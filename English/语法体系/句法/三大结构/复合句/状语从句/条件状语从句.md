## 概念

Adverbial Clause of Condition）

> 定义：表示主句动作或状态发生条件的从句，即"如果...就..."

## 基本结构

```text
If + 陈述句（条件），主句（结果）
```

连接词：

| 连接词 | 含义 |
|--------|------|
| **if** | 如果 |
| **unless** | 除非；如果不（= if ... not） |
| **as long as** | 只要 |
| **in case** | 以防 |

## if 引导的条件句：两大常用形式

### 形式 1：主将从现

```text
if 从句：一般现在时
主句：  一般将来时（will + 动词原形）
```

```text
If it rains, I will stay at home.
如果下雨，我就待在家。
```

### 形式 2：主情从现

```text
if 从句：一般现在时
主句：  情态动词（can/may/must...）+ 动词原形
```

```text
If it rains, we can watch a movie at home.
如果下雨，我们可以在家看电影。
```

### 口诀记忆

| 口诀   | 含义                   |
| ---- | -------------------- |
| 主将从现 | 主句用将来时，if 从句用一般现在时   |
| 主情从现 | 主句用情态动词，if 从句仍用一般现在时 |

> ⚠️ 核心规则：if 条件从句中不用将来时，表将来一律用一般现在时。

```text
If it will rain tomorrow...     ✘
If it rains tomorrow...         ✔
```

## 例句拆解

```text
If it rains, we can watch a movie at home.
└─ 从句 ─┘ └──────── 主句 ────────┘
一般现在时     情态动词 + 动词原形
```

```text
If it rains, I will stay at home.
└─ 从句 ─┘ └────── 主句 ──────┘
一般现在时      will + 动词原形
```

## 拓展：unless 与 if ... not

```text
Unless you study hard, you will fail the exam.
= If you don't study hard, you will fail the exam.
除非你努力学习，否则考试会不及格。
```

> 💡 unless = if ... not，二者可互换，但使用时注意否定意义的转换。

## 拓展：条件状语从句 vs if 引导的宾语从句

| 类型     | 时态规则        | 例句                                                |
| ------ | ----------- | ------------------------------------------------- |
| 条件状语从句 | 从句用一般现在时表将来 | If it rains, I will stay home.（如果下雨……）            |
| 宾语从句   | 时态按实际意义选择   | I don't know if it will rain tomorrow.（不知道明天是否下雨） |

> 💡 判断技巧：if 表"是否"引导宾语从句，位于动词/介词之后；if 表"如果"引导条件状语从句，可放在句首或主句之后。

## 速记口诀

- if 从句表条件，"如果...就..."记心间
- 主将从现是铁律，if 从句现在时
- 主情从现也一样，can/may/must 配原形
- unless 等于 if not，否定转换要小心
