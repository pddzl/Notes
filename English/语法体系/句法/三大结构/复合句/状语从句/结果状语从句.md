## 概念

Adverbial Clause of Result

> 在句中说明某件事情或某个行动所产生的结果的从句

## 基本结构

```text
主句 + so + 形容词/副词 + that + 陈述句（结果）
```

> 💡 核心逻辑：主句程度如此...，以至于产生后面的结果。


```text
The box was so heavy that I couldn't lift it.
└────── 主句 ──────┘ └──── 结果从句 ────┘
箱子太重了，以至于我举不起来

I followed the recipe so carefully that the dish tasted delicious.
我严格按照食谱来做，菜尝起来很美味
```

## such ... that ... 

当名词前需要限定词（a/an/the/this 等）时，用 such ... that ...

```text
such + (a/an) + 形容词 + 名词 + that + 陈述句
```

```text
It was such a heavy box that I couldn't lift it.
箱子太重了，以至于我举不起来。
```

### 两者对比

| 结构                               | 中心词      | 例句                        |     |
| -------------------------------- | -------- | ------------------------- | --- |
| so + adj./adv. + that            | 形容词 / 副词 | so heavy that ...         |     |
| such + (a/an) + adj. + 名词 + that | 名词       | such a heavy box that ... |     |

##  too ... to ... 

结果状语从句so/such ... that ...可与"too ... to ..."（太...而不能...）互换：

```text
The box was so heavy that I couldn't lift it.
= The box was too heavy for me to lift.

He is so young that he can't go to school.
= He is too young to go to school.
```
