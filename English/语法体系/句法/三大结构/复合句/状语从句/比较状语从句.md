## 定义

`Adverbial Clause of Comparison`

> **定义**：对主句中的人或事物进行比较的状语从句，最常用的结构是 **as ... as ...**。

## as ... as ... 

> **含义**：和……一样……

### 基本形式

```text
as + 形容词/副词原级 + as + 比较对象
```

| 形式              | 例句                                         |
| --------------- | ------------------------------------------ |
| as + 形容词原级 + as | She is as tall as her mother.（她和她妈妈一样高。）   |
| as + 副词原级 + as  | You are as early as Tom is.（你和 Tom 到得一样早。） |

> ⚠️ 两个 as 之间必须用原级，不能出现比较级。

## not as ... as ... 

> **含义**：不如……那样……

### 基本形式

```text
not + as + 形容词/副词原级 + as + 比较对象
```

```text
This book is not as interesting as that one.
这本书不如那本有趣。
```

> 💡 也可用 **not so ... as ...**，含义相同，语气稍强：

```text
This book is not so interesting as that one.
```

## as ... as possible

> **含义**：尽可能...

### 基本形式

```text
as + 形容词/副词原级 + as possible
```

```text
I must arrive as early as possible.
我必须尽可能早到

Please come as soon as possible.
请尽快来
```
