## 定义 

Adverbial Clause of Reason

> **定义**：用来说明主句中事情发生原因的从句。

### 基本结构

```text
主句 + 连接词 + 完整的句子（陈述语序）
```

## 三大连接词

| 连接词     | 语气 / 用法             | 位置特点    | 例句                                                                             |
| ------- | ------------------- | ------- | ------------------------------------------------------------------------------ |
| because | 语气最强，回答 why，直接说明原因  | 主句前或后均可 | I slept too late last night because my cat was ill.（昨晚我睡得太晚，因为我的猫病了。）          |
| as      | 语气较弱，多用于**双方已知**的原因 | 多在主句之前  | As we have to finish the work today, I can't let you go.（由于我们今天必须完成工作，我不能让你走。） |
| since   | 语气较弱，既然（已知原因，无需证明）  | 多在主句之前  | Since I have a cat too, I understand how you feel!（既然我也养猫，我理解你的感受！）            |

## 语气强弱对比

```text
because  >  since / as
最强         较弱（多为已知原因）
```

## 使用要点

### because 不与 so 连用

```text
Because it was raining, so I stayed home.   ✘
Because it was raining, I stayed home.      ✔
It was raining, so I stayed home.           ✔
```

> 💡 中文说"因为...所以..."，英语只能说其一：because 和 so 二选一

### because 与 because of 的区别

| 形式                 | 后接    | 例句                                    |
| ------------------ | ----- | ------------------------------------- |
| because + 句子       | 完整句子  | I stayed home because it was raining. |
| because of + 名词/短语 | 名词性成分 | I stayed home because of the rain.    |
