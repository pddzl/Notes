## 什么是复合句

复合句（Complex Sentence）由：

> **一个独立分句 + 一个或多个从属分句**

组成。

也就是说：

```text
主句 + 从句
```

从句不能独立表达完整意思，需要依附于主句。

例如：

```text
I stayed home because it was raining.
```

这里：

```text
I stayed home
```

是主句，可以独立成句。

```text
because it was raining
```

是从句，不能单独作为完整句子。

## 简单句、并列句、复合句的区别

| 类型      | 核心结构        | 例子                                    |
| ------- | ----------- | ------------------------------------- |
| **简单句** | 一个独立分句      | I stayed home.                        |
| **并列句** | 独立分句 + 独立分句 | I stayed home, and she went out.      |
| **复合句** | 主句 + 从句     | I stayed home because it was raining. |

## 判断方法

遇到一个长句子，可以先找：

> **有几个“可以独立成句”的部分？**

### 一个独立分句

→ **简单句**

```text
I stayed home.
```

### 两个独立分句

→ **并列句**

```text
I stayed home, and she went out.
```

```text
I stayed home.
She went out.
```

两个部分都可以独立成句。

### 一个独立分句 + 一个不能独立成句的从句

→ **复合句**

```text
I stayed home because it was raining.
```

```text
I stayed home.
```

可以独立。

但是：

```text
Because it was raining.
```

不能独立表达完整意思。

## 三个结构的核心区别

```text
简单句

一个独立分句
↓
I stayed home.
```

```text
并列句

独立分句 + 独立分句
↓
I stayed home, and she went out.
```

```text
复合句

独立分句 + 从句
↓
I stayed home because it was raining.
```

可以简单记成：

> **简单句 = 一个完整句子**
>
> **并列句 = 两个完整句子并列**
>
> **复合句 = 主句 + 从句**

## 后续学习重点

复合句是英语长难句的核心。

复合句中的从句主要可以继续分为：

1. **名词性从句**
2. **定语从句**
3. **状语从句**

例如：

```text
I know that he is right.
```

→ 名词性从句

```text
The man who lives next door is a doctor.
```

→ 定语从句

```text
I stayed home because it was raining.
```

→ 状语从句

因此可以把英语句子结构理解成：

```text
句子
│
├── 简单句
│
├── 并列句
│
└── 复合句
    │
    ├── 名词性从句
    ├── 定语从句
    └── 状语从句
```
