

## 定义

什么是"同位语"

> 紧挨在前一个名词之后，用另一种说法对前者进行**解释、说明**的成分，两者指同一事物。

```text
This is FunIsland, the new amusement park.
           ↑                ↑
         名词         FunIsland 的同位语
```

这就是欢乐岛——那座新的游乐园。

什么是同位语从句 `Appositive Clause`

> 对前面的抽象名词进行**解释说明**的从句，从句与名词指同一内容。

## 基本结构

```text
抽象名词 + 连词 + 解释说明的完整句子
```

| 结构                                      | 说明                     |
| --------------------------------------- | ---------------------- |
| that + 陈述句                              | 最常用，that 无实义，不在从句中充当成分 |
| whether + 陈述句                           | 表示"是否"                 |
| what / when / where / why / how 等 + 陈述句 | 连接词在从句中充当相应成分          |

> ⚠️ 同位语从句内部使用**陈述句语序**。

例句：

```text
It was your idea that we make faces and take photos.
                      └────────── 同位语从句 ──────────┘
               ↑
          idea 的同位语，解释"主意"的具体内容
```

"我们做鬼脸拍照"是你的主意。

## 常见搭配同位语从句的抽象名词

| 类别     | 名词                                       |
| ------ | ---------------------------------------- |
| 想法、观点  | idea, thought, belief, opinion, view     |
| 事实、信息  | fact, truth, news, information, evidence |
| 疑问、可能性 | question, doubt, possibility, chance     |
| 消息、决定  | message, report, decision, promise, hope |


## 同位语从句 vs 定语从句

两者都跟在名词之后，容易混淆，关键区别如下：

| 对比项      | 同位语从句                  | 定语从句                   |
| -------- | ---------------------- | ---------------------- |
| 作用       | **解释说明**名词的具体内容（"是什么"） | **修饰限定**名词（"哪一个/什么样的"） |
| that 的角色 | 仅起连接作用，**不作成分**        | 充当成分（主语/宾语）            |
| 名词特点     | 多为抽象名词                 | 任意名词                   |

```text
The news that he won the game is true.
   └────── 同位语从句：说明 news 的具体内容 ──────┘
（他赢了比赛这个消息是真的。）

The news that he told me is true.
    └──── 定语从句：that 作 told 的宾语，修饰 news ────┘
（他告诉我的那个消息是真的。）
```

> 💡 判断技巧：去掉 that 从句后，名词内容**不完整、说不清** → 同位语从句；名词指代**依然明确** → 定语从句。

## 速记口诀

- 名词之后跟从句，先问"解释"还是"修饰"
- 解释内容是同位，限定范围是定语
- that 不作成分为同位，that 充当成分多为定语
