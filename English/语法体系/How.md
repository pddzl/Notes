# 用法

How 的用法可以分成三大类：

1. 疑问句
2. 从句
3. 感叹句

# 疑问句

How 用于直接提问，主要表示：

- 怎么、如何
- 多么、多少、多久、多远、多频繁等

## How + 动词

表示“怎么、如何”

结构：

```text
How + 一般疑问句语序？
```

例：

```text
How did he solve the problem?
他是怎么解决这个问题的

How does it work?
它是怎么工作的

How can I fix this problem?
我该怎么解决这个问题
```

## How + 形容词

表示“有多……”

结构：

```text
How + 形容词 + 一般疑问句语序？
```

例：

```text
How difficult is the problem?
这个问题有多难

How important is it?
它有多重要

How expensive is the car?
这辆车有多贵
```

## How + 副词

表示“……得有多……”。

结构：

```text
How + 副词 + 一般疑问句语序？
```

例：

```text
How quickly can you finish it?
你多快能完成它

How carefully did he check the system?
他检查系统检查得有多仔细
```

## How + 程度 / 时间 / 距离 / 频率

常见结构：

| 结构        | 含义        | 例句                            |
| --------- | --------- | ----------------------------- |
| how much  | 多少；多少钱；多么 | How much does it cost?        |
| how many  | 多少个       | How many servers do you have? |
| how long  | 多久；多长     | How long did you wait?        |
| how far   | 多远        | How far is the station?       |
| how often | 多久一次      | How often do you check it?    |
| how soon  | 多快；多久以后   | How soon can you finish it?   |
| how old   | 多大年龄      | How old is he?                |

# 从句

How 可以引导名词性从句，表示：

> 如何、怎样；有多...

最重要的特点：

> 从句使用陈述句语序，而不是疑问句语序

## how + 陈述句

表示“如何、怎样”

**结构：**

```text
how + 主语 + 谓语
```

例：

直接疑问句：

> How did he solve the problem?

变成从句：

> I know how he solved the problem.
> 我知道他是怎么解决这个问题的

## how + 形容词 + 陈述句

表示“有多……”。

**结构：**

```text
how + 形容词 + 主语 + 谓语
```

例：

直接疑问句：

> How difficult is the problem?

从句：

> I don't know how difficult the problem is.
> 我不知道这个问题有多难

## how + 副词 + 陈述句

表示“……得有多……”。

**结构：**

```text
how + 副词 + 主语 + 谓语
```

例：

> I don't know how quickly he solved it.  
> 我不知道他多快就解决了它

## How 引导主语从句

How 引导的从句可以整体充当主语。

例：

```text
How he solved the problem is still unknown.  
他是如何解决这个问题的仍然是未知的。

How she learned English so quickly surprised me.  
她是如何这么快学会英语的让我很惊讶。
```

# 感叹句

How 用于感叹句时，表示：

> 多么...!

主要修饰形容词或副词

## How + 形容词 + 主语 + 谓语

**结构：**

```text
How + 形容词 + 主语 + 谓语！
```

例：

```text
How beautiful she is!  
她真漂亮！

How difficult the problem is!  
这个问题真难！

How important this is!  
这真重要！
```

## How + 副词 + 主语 + 谓语

**结构：**

```text
How + 副词 + 主语 + 谓语！
```

例：

```text
How quickly he runs! 
他跑得真快!

How carefully she works! 
她工作得真仔细!
```

# 三大用法对比

| 类型  | 核心含义     | 语序                      | 例句                       |
| --- | -------- | ----------------------- | ------------------------ |
| 疑问句 | 怎么 / 多…  | 疑问句语序                   | How did he solve it?     |
| 从句  | 如何 / 有多… | 陈述句语序                   | I know how he solved it. |
| 感叹句 | 多么…      | How + adj/adv + 主语 + 谓语 | How difficult it is!     |

# 一句话总结

> How 的核心是“方式或程度”，语法上主要看它是在直接提问、引导从句，还是表达感叹

```text
How
│
├── 1. 疑问句
│   ├── How + 动词…？
│   ├── How + 形容词…？
│   ├── How + 副词…？
│   └── how much / many / long / far / often / soon / old...
│
├── 2. 从句
│   ├── how + 主语 + 谓语
│   ├── how + 形容词 + 主语 + 谓语
│   └── how + 副词 + 主语 + 谓语
│
└── 3. 感叹句
    ├── How + 形容词 + 主语 + 谓语！
    └── How + 副词 + 主语 + 谓语！
```
