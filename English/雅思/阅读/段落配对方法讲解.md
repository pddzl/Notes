## 雅思阅读的题型顺序

### ① 顺序出题

  
|  项目  |  内容 |
| --- | --- |
| 题型 | 填词题、判断题、选择题 |

| 步骤 | 1. 划出这道题的定位和关键信息（判断题划这道）<br>2. 带回文章扫读，直到扫到定位<br>3. 对比题干，判断答案<br>4. 划下一道题，接着之前的定位往后读，循环步骤 |

  

### ② 乱序出题

| 项目  | 内容                                                      |
| --- | ------------------------------------------------------- |
| 题型  | 段落配对、小标题                                                |
| 步骤  | 1. 划出所有题干的定位和关键信息<br>2. 以段落为单位扫读<br>3. 读完一段回题干对比一次，判断答案 |

## 注意事项

  

- 段落配对题考查细节，不需要理解段落内容

- 一般情况下，不需要扫完整段落

- 有 NB 提示，需要把段落扫完

  

## 特殊定位词

  

### ① 重复词

  

- 每道题重复出现的词，和文章标题词，不能作定位

  

### ② 可以具体化的概括词

  

- **数字类**

- 时间：period → 10 years

- 金钱：financial / cost / money → ¥200

- 比例：proportion / rate / ratio → 2%

- 数据：data / statistic / number → 1

- **复数类**

- stages：first...then...now...

- books, animals

- **专有名词类**

- location → Paris

- term → Artemisia

  

## 具体化预判的 4 个层面

  

### ① 宽泛名词

  

- 数字类

- 复数类

- 专有名词类

  

### ② 情感指向

  

- **正向情感指示词**：positive / beneficial / increase / grow / improve ...

- **负向情感指示词**：negative / not / decline / damage / lost ...

  

### ③ 逻辑关系

  

- **并列或举例**

- 题干：examples of / an example of / different ...

- 原文：and / or / also / similarly / such as ...

- **因果**

- 题干：reason / why / result / outcome ...

- 原文：because / why / since / as a result / show ...

- **时间**

- 题干：before / prior / then / first ...

- 原文：关于时间的描述

- **比较**

- 题干：than / more ...

- 原文：比较关系
