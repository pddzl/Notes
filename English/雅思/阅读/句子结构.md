## 句子结构1

| **句子结构1** | 句子的主语被介词短语修饰                                                                                                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法**  | 跳过介词短语部分，找准主语；再读修饰                                                                                                                                                              |
| **示例**    | **The** small **cat** in the house with the blue roof **was sleeping**.  <br>  <br>先理解主谓宾：  <br>The cat was sleeping.  <br>再理解修饰（什么样的猫？）  <br>small；in the house with blue roof |

## 句子结构2

| **句子结构2** | 句中包含**be动词**的5种形式，或者**情态动词**（如：can, should）、**助动词**（如：have, does）                                                                                        |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法**  | 如果句子中出现上述结构，则可以直接判断其对应部分为句子的谓语，快速抓住句子主干。                                                                                                                 |
| **示例**    | The student in the library with a stack of books beside him **should focus on** his research.  <br>出现了情态动词“**should**”，因此“**should focus on**”就是句子的谓语。\| |

## 句子结构3

| **句子结构** | 句子的宾语被形容词、量词短语和介词短语等修饰                                                                                                                                                                        |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | 跳过介词短语等修饰成分，先抓主干                                                                                                                                                                              |
| **示例**   | **She picked** some fresh **flowers** from the garden.  <br>她从花园里摘了一些鲜花。  <br>  <br>先找主干：She（主语） picked（谓语） flowers（宾语）  <br>再找宾语的修饰成分：  <br>“some 一些”、“fresh 新鲜的”和介词短语“from the garden 从花园里” |

## 句子结构4
| **句子结构** | 名词后出现介词短语叠加                                                                                                                                                                                                                                                                                                 |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | 先理解名词，然后按介词短语顺序逐步理解，最后按照中文语序调整顺畅                                                                                                                                                                                                                                                                            |
| **示例**   | **The study** of ancient languages at famous universities for historical research.  <br>  <br>1. 先找准**中心名词**：  <br>“the study”  <br>2. 再将修饰断开，**依次**理解：  <br>of ancient languages /at famous universities /for historical research  <br>古代语言的/ 在著名大学/ 为历史研究  <br>3. 根据中文，大致理顺含义：  <br>在著名大学为了历史研究，对古代语言的研究。 |

## 句子结构5
| **句子结构** | 句子中的名词被不定式“to do”修饰                                                                                                                                                                                                                                                                      |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | 紧跟主语的不定式，通常在修饰名词，不是主干，可先跳过不读，接着再来依次读修饰，理解大意。                                                                                                                                                                                                                                             |
| **示例**   | **A project** to build new parks in the city **has gained popularity** among residents.  <br>在城市中建造新公园的**项目**在居民中**越来越受欢迎**。  <br>  <br>句子主干是：A project（主） has gained（谓） popularity（宾）  <br>“to build new parks in the city”修饰主语，表示这个项目是“在城市里修建新的公园”；“among residents”修饰宾语，表示“在居民中”很受欢迎。 |

## 句子结构6

| **句子结构** | 句子中的动词-ing形式修饰名词                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | 先跳过动词-ing的部分不读，抓住主干                                                                                                           |
| **示例**   | The cute girl **playing in the park** is my sister.**在公园玩耍**的这个可爱女孩是我的妹妹。  <br>  <br>动词-ing形式“playing in the park”修饰主语“girl”。 |

## 句子结构7

| **句子结构** | 句子中的名词，后紧跟过去分词短语作为修饰                                                                                                                      |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | 当遇到**过去分词短语**时，**先跳过不读**，**直接理解句子的主干结构**，之后再回到过去分词短语理解其修饰的内容。  <br>判断过去分词的方法：名词跟后面的过去分词是**被动**关系。                                         |
| **示例**   | The poetry **created by the poet** is gaining popularity.  <br>这位诗人创作的诗歌越来越受欢迎。  <br>  <br>“created by the poet (**被诗人创作**)”修饰主语“poetry”。 |

## 句子结构8

| **句子结构** | **主系表结构中，系动词比较特殊。**  <br>比如：“**remain**”，“**stay**”，“**turn out**”，“**turn out to be**”，以及“**prove to be**”。 |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| **阅读方法** | 直接简化理解为“be”，即“是”。                                                                                            |
| **示例**   | The movie **turned out to be** (= **be**) really funny.  <br>这部电影**是**非常搞笑的。                                 |

## 句子结构 9

| **句子结构** | 被动句（含有A be done by B的结构）                                                                                                                                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | 将A和B的位置对换，把动作发出者B放在最前面，**使其成为主动语态**。  <br>（如果句子本身比较简单，直接理解即可）                                                                                                                                                                                  |
| **示例**   | The employees' pressure **can be relieved by** having enough time to enjoy themselves and relax.  <br>  <br>转化为主动句：  <br>Having enough time to enjoy themselves and relax **can relieve** the employees' pressure.  <br>有足够的时间休闲**可以缓解**员工的压力。 |

## 句子结构 10

| **句子结构** | 表原因的介词短语在句子的开头或者结尾，修饰整个句子。  <br>常见短语：due to ... ; because of ...                                                                                       |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **阅读方法** | 先跳过不读，关注主干；阅读时，注意分辨因果关系。                                                                                                                               |
| **示例**   | The train was delayed (结果) **due to** heavy rain (原因).  <br>火车**因**大雨而延误。  <br>  <br>He stayed home（结果） **because of** a cold（原因）.  <br>他**因为**感冒呆在家里。 |

## 句子结构 11

| **句子结构** | 表示方式的介词短语在句子开头或结尾，修饰整个句子。  <br>常见短语：by ...; through ...                                                                                                                    |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | 先读主干，再读修饰；注意“by/through”之后跟的是达成某件事的**方式或者途径**。                                                                                                                             |
| **示例**   | She saved money **by** cooking at home instead of eating out.  <br>她**通过**在家做饭而不是外出就餐来省钱。  <br>  <br>He solved the problem **through** hard work.  <br>他**通过**努力工作解决了这个问题。 |

## 句子结构12

| **句子结构** | 非谓语修饰整个句子                                                                                                                                |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | 在阅读时，先识别非谓语，跳过不读，把握主干后，再来读。  <br>识别方法：非谓语通常以“动词ing”、“to do不定式”以及“动词过去分词”形式**单独出现**，通常用来说明整句话的背景，比如原因、目的、结果等。                             |
| **示例**   | **To win the competition**, you **have to train** diligently.  <br>要赢得比赛，你必须勤奋训练。  <br>  <br>先看主干“you **have to train**”，再读修饰，句首的不定式表目的。 |

## 13.

| **句子结构** | “and”连接的并列结构：词跟词的并列                                                                                                                                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | **先识别其中简单的**、**认识的**单词，根据并列结构特点，**推测下**并列结构中其他单词的**大致含义**，然后继续往下读。  <br>  <br>并列结构特点：  <br>1. 词性相同  <br>2. 词义类似，同一主题或者类别  <br>3. 在句子中的功能相同                                                                                                        |
| **示例**   | The speech presented by the professor was **edifying**, **perspicacious**, **thought-provoking**, **and impressive** for everyone.  <br>这位教授的演讲富**有教育意义**、**见解深刻**、**引人深思且令人印象深刻**。  <br>  <br>“impressive”表示令人印象深刻的，由并列结构特点可知，前面的复杂形容词的含义应该也为褒义。 |

## 14.

| **句子结构** | “and”连接的并列结构：两个较复杂结构的并列（如介词短语）                                                                                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | 根据结构是否一致，识别并列关系。注意：结构相同才相互并列。                                                                                                                                                               |
| **示例**   | The flowers **in the garden** and **by the front door** need watering.**花园里的**花和**前门旁边的**花需要浇水。  <br>  <br>并列：“in the garden”和“by the front door”都是介词短语，被“and”连接，因此是并列关系，都是在描述“flowers”的位置。 |

## 15.

| 句子结构 | 复合句：包含若干个由连接词（if, because, how ... ）连接的分句                                                                                                                                                             |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 阅读方法 | 先找到**连接词**，将分句拆解开；  <br>再分别抓住每个**分句**的**主干**，最后读修饰。                                                                                                                                                   |
| 示例   | They postponed the event **because** the weather forecast predicted rain.  <br>  <br>分句1：They postponed the event 他们推迟了这次活动  <br>连接词：because 因为  <br>分句2：the weather forecast predicted rain 天气预报说会下雨 |

## 16.

| 句子结构 | 复合句中包含由连接词（because, since, as, in that, considering that, given that）引导的原因状语从句。                                                                |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 阅读方法 | **先找到连接词**，将分句拆解开；  <br>再分别抓住每个**分句**的**主干**，判断分句之间的**因果关系**，读懂大意；最后读修饰。                                                                       |
| 示例   | I was late for work **as** the traffic was heavy.  <br>  <br>分句1：I was late for work 我上班迟到了  <br>连接词：as 由于  <br>分句2：the traffic was heavy 交通拥堵 |

## 17.

| 句子结构 | 复合句中包含由连接词（although, though, even though, even if）引导的让步状语从句。                                                                                                                         |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 阅读方法 | 先找到**连接词**，将分句拆解开；  <br>再分别抓住每个**分句**的**主干**，识别“让步”逻辑，读懂大意；  <br>最后读修饰。                                                                                                              |
| 示例   | **Even though** she doesn't like coffee, she ordered a cappuccino.  <br>  <br>连接词：even though 即使  <br>分句1：she doesn't like coffee 她不喜欢咖啡  <br>分句2：she ordered a cappuccino 她点了一杯卡布奇诺 |

## 18.

| 句子结构 | 复合句中包含由“that, what, who, whom, whose, which, when, where, why, how”引导的宾语/主语/表语从句。                                                                                                                             |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 阅读方法 | **先找到连接词**，将分句拆解开；  <br>再分别抓住每个**分句**的**主干**，识别从句对应的成分，读懂大意；  <br>最后读修饰。                                                                                                                                      |
| 示例   | **宾语从句：**  <br>He asked **when** the meeting starts.  <br>他询问会议什么时候开始。  <br>**主语从句：**  <br>**What** we need is more time.  <br>我们需要的是更多的时间。**表语从句：  <br>**This is **what** I wanted to buy.  <br>这就是我想要购买的东西。 |

## 19.

| **句子结构** | 主干的主语和谓语之间，插入了若干定语从句。                                                                                                                                                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **阅读方法** | 跳过定语从句，先抓住主句的谓语以及主干，再回头理解定语从句提供的细节。  <br>抓主句谓语的方法：  <br>从句谓语往往紧跟在连接词（如“that, which, who”）之后，需跳过从句谓语，找到主句谓语。                                                                                                                                                   |
| **示例**   | The teacher **who** inspired me to study harder is retiring soon.  <br>  <br>定语从句“who inspired me to study harder”修饰“teacher”，“inspired”紧跟在连接词“who”之后，是从句谓语；后面的“is”才是主句谓语。  <br>句子主干是：The teacher is retiring soon.（这位老师快要退休了。）  <br>整句话含义：激励我努力学习的老师就就快要退休了。 |

## 20.

| 句子结构 | 主干的主语和谓语之间，插入了一个非限制性定语从句。                                                                                                                                                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 阅读方法 | 跳过从句，先找到主句谓语，抓住主干。                                                                                                                                                                                                                                      |
| 示例   | The concert, **which** lasted for three hours, was enjoyed by everyone present.  <br>  <br>“which”引导非限定性定语从句“which lasted for three hours”修饰“concert”，意思是“持续了三个小时的音乐会”；  <br>句子主干则是“The concert was enjoyed by everyone present”，意思是“这场音乐会受到了在场所有人的喜爱”。 |

## 21.

| 句子结构 | 句子包含前后用逗号隔开的**插入语**。                                                                                                                                                          |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 阅读方法 | 先跳过插入语，关注句子的主干部分，再回来读插入语。                                                                                                                                                     |
| 示例   | **The project**, despite numerous setbacks, **was completed on time**.  <br>  <br>插入语：despite numerous setbacks（尽管有许多挫折）  <br>句子主干：The project was completed on time（项目按时完成了） |
