## 1. 雅思阅读考试基本结构

| 项目   | 内容                            |
| ---- | ----------------------------- |
| 考试类型 | IELTS Academic Reading（学术类阅读） |
| 文章数量 | 3 篇                           |
| 题目数量 | 40 道                          |
| 考试时间 | 60 分钟                         |
| 总分方式 | 每题答对得 1 分，按正确题数换算阅读成绩         |
| 文章来源 | 书籍、期刊、杂志、报纸等类型的文章             |

考试固定的是整体结构，而不是每次必考哪些题型。不同试卷的题型组合可能不同；一套试卷可能出现多种题型，也不会保证 14 种题型全部出现

## 2. 阅读题型总览（14 种常见形式）

以下将官方题型及常见填空形式拆分成 14 种便于学习的类别。

|   # | 题型                                  | 中文名称         | 核心考查          | 类型  |
| --: | ----------------------------------- | ------------ | ------------- | --- |
|   1 | Sentence Completion                 | 句子填空         | 定位、同义替换、词性    | 填词题 |
|   2 | Short Answer Questions              | 简答题          | 定位和精准提取信息     | 填词题 |
|   3 | Table Completion                    | 表格填空         | 信息提取、表格逻辑     | 填词题 |
|   4 | Note Completion                     | 笔记填空         | 信息提取、概括       | 填词题 |
|   5 | Summary Completion                  | 摘要填空         | 段落理解、同义替换     | 填词题 |
|   6 | Flow-chart Completion               | 流程图填空        | 步骤和顺序理解       | 填词题 |
|   7 | Diagram Labeling / Label Completion | 图表标注填空       | 位置、结构、方位理解    | 填词题 |
|   8 | Matching Sentence Endings           | 句子配对         | 句意、逻辑关系       |     |
|   9 | True / False / Not Given            | 事实判断         | 判断原文事实是否一致    |     |
|  10 | Yes / No / Not Given                | 观点判断         | 判断作者观点或主张     |     |
|  11 | Matching Headings                   | 段落标题匹配 / 小标题 | 段落中心思想        |     |
|  12 | Matching Features                   | 名词配对         | 人物、事物、观点与特征对应 |     |
|  13 | Matching Information                | 段落信息匹配       | 找出具体信息所在段落    |     |
|  14 | Multiple Choice                     | 选择题          | 细节、主旨、推理、排除干扰 |     |

> 不同教材或资料可能把填空题细分、合并，或使用略有不同的题型名称，因此"14 种"是本学习计划使用的分类方式。

## 3. 题型难度参考排序

此排序是学习建议，不是官方难度排名。实际难度会因文章、题目、词汇和个人能力而变化。

### 第一等级：相对容易（★）

1. Sentence Completion — 句子填空
2. Short Answer Questions — 简答题
3. Table Completion — 表格填空
4. Note Completion — 笔记填空

特点：
- 答案通常能在原文中找到
- 主要练习关键词定位、同义替换、词性判断和字数限制

### 第二等级：中等（★★）

5. Summary Completion — 摘要填空
6. Flow-chart Completion — 流程图填空
7. Diagram Labeling — 图表标注填空
8. Matching Sentence Endings — 句子配对

特点：
- 不只需要定位，还要理解上下文、信息归纳、步骤或逻辑关系

### 第三等级：中高难度（★★★）

9. True / False / Not Given — 事实判断
10. Yes / No / Not Given — 观点判断

特点：
- 需要准确区分一致、矛盾和未提及
- 观点题还需要判断作者立场，不能把他人观点误认为作者观点

### 第四等级：较难（★★★★）

11. Matching Headings — 段落标题匹配
12. Matching Features — 特征匹配

特点：
- 需要理解段落整体意思或建立人物、观点、事实之间的关系
- 不能只根据单个关键词作答

### 第五等级：高难度（★★★★～★★★★★）

13. Matching Information — 段落信息匹配
14. Multiple Choice — 选择题

特点：
- Matching Information 需要在全文中寻找具体信息，题目可能乱序，且一个段落可能包含多项信息
- Multiple Choice 的难度取决于单选/多选、主旨/细节/推理，以及干扰选项的设计

## 4. 题型出现频率与备考优先级

IELTS 官方没有公布一份所有考试固定遵循的题型概率表，也没有规定每套试卷必须出现某种题型、某种数量。以下频率标签仅是备考经验参考，不能视为官方统计概率或保证

### 第一梯队：优先熟练掌握

- Matching Headings — 段落标题匹配
- True / False / Not Given — 事实判断
- Multiple Choice — 选择题
- Sentence Completion — 句子填空
- Matching Information — 段落信息匹配
- Summary Completion — 摘要填空

### 第二梯队：重点掌握

- Matching Features — 特征匹配
- Yes / No / Not Given — 观点判断
- Table Completion — 表格填空
- Note Completion — 笔记填空
- Flow-chart Completion — 流程图填空

### 第三梯队：掌握方法即可，仍需练习

- Diagram Labeling — 图表标注
- Matching Sentence Endings — 句子配对
- Short Answer Questions — 简答题

**注意：** 第三梯队不代表可以不学。只是这些题型通常能借助定位、词性判断、同义替换和上下文等基础技能来处理，单独投入大量时间训练的必要性可能相对较低

## 5. 题型答案顺序：顺序题、乱序题与灵活题

做题时需要判断：题目答案是否按文章信息出现的顺序排列。顺序规律能帮助减少重复扫描，但不要把“通常”误当成绝对规则

### 5.1 顺序性较强的题型（ORDER）

| 题型                        | 顺序规律        | 做题策略            |
| ------------------------- | ----------- | --------------- |
| Sentence Completion       | 通常按原文信息顺序   | 找到上一题后，继续向后定位   |
| Short Answer Questions    | 通常按原文顺序     | 逐题向后定位          |
| Matching Sentence Endings | 题目开头通常按原文顺序 | 先定位句子前半部分，再匹配结尾 |
| True / False / Not Given  | 通常按原文顺序     | 一般可从上一题位置继续向后找  |
| Yes / No / Not Given      | 通常按原文顺序     | 顺着作者观点出现的顺序定位   |

### 5.2 乱序题（NON-ORDER）

| 题型 | 顺序规律 | 做题策略 |
|---|---|---|
| Matching Headings | 标题选项顺序不对应段落顺序 | 逐段抓中心思想 |
| Matching Information | 题目顺序不保证对应文章段落 | 根据题目关键词扫描全文 |
| Matching Features | 人物/事物/选项与信息的对应通常乱序 | 按人物或特征建立对应关系 |

### 5.3 灵活题（FLEXIBLE）

这些题型可能有局部顺序、内容逻辑或空间/流程规律，但不能一概依赖原文顺序

| 题型                    | 规律                             | 做题策略                         |
| --------------------- | ------------------------------ | ---------------------------- |
| Summary Completion    | 摘要空格的答案可能与摘要结构相关；不要未经确认就假定严格顺序 | 先定位摘要对应的原文区域，再逐空确认           |
| Note Completion       | 常按笔记主题或原文局部结构组织                | 判断笔记对应哪个段落或信息块               |
| Table Completion      | 表格可能按类别、时间或比较维度组织              | 先理解表格行列关系，再定位                |
| Flow-chart Completion | 流程本身通常有步骤逻辑                    | 按流程步骤寻找信息，注意流程顺序不一定等同于文章段落顺序 |
| Diagram Labeling      | 标签答案受图中位置和结构约束                 | 根据方位、结构和描述定位                 |
| Multiple Choice       | 一组题目常有一定顺序性，但不同题目形式与考点可能变化     | 通常逐题定位；不要把顺序当成绝对保证           |

### 顺序规律的使用原则

- 顺序题：找到前一题答案后，通常可以继续向后搜索，不必回到文章开头
- 乱序题：不要依赖题目顺序；通过关键词、同义替换和段落扫描定位
- 灵活题：先判断题目组织方式，再决定是否利用顺序
- **无论何种题型，最终都必须回到原文上下文确认答案**

## 6. 顺序题的做题示例

假设文章结构如下：

| 段落 | 内容 |
|---|---|
| Paragraph A | 背景介绍 |
| Paragraph B | 早期研究 |
| Paragraph C | 研究发现 |
| Paragraph D | 实验过程 |
| Paragraph E | 研究争议 |
| Paragraph F | 未来发展 |

问题：

1. 早期研究的主要目的
2. 研究得出的结论
3. 实验采用的方法

假设答案分别在 B、C、D 段

对于顺序题，可以建立连续的阅读路径：

**Paragraph B → Q1 → Paragraph C → Q2 → Paragraph D → Q3**

找到 Q1 后，继续向后寻找 Q2、Q3，减少重复扫描

## 7. 乱序题的做题示例

假设文章结构如下：

| 段落 | 内容 |
|---|---|
| A | 研究背景 |
| B | 科学家 Smith 的研究 |
| C | 科学家 Johnson 的研究 |
| D | 一项实验失败的原因 |
| E | 新技术的发展 |

题目：

1. What caused the experiment to fail?
2. Which scientist developed the theory?
3. What was the new technology used for?

答案可能分布为：

| 题目 | 答案所在段落 |
|---|---|
| Q1 | D |
| Q2 | B |
| Q3 | E |

这时不能按照 Q1 → Q2 → Q3 的顺序，假设答案在文章中也依次向后出现

### 乱序题的解题流程

1. 提取题目关键词：人名、年份、特殊名词、核心概念
2. 扫描全文：寻找关键词及其同义替换
3. 确定段落：判断信息出现在哪个段落
4. 精读上下文：确认答案并排除干扰信息

## 8. 阅读的四种核心能力

雅思阅读的题型表面上不同，但底层主要考查以下四种能力

### 8.1 定位能力（Scanning）

快速从文章中找到题目涉及的信息

例如，题目出现某个年份、人物或专有名词时，先利用这些明显信息定位，再读上下文

### 8.2 同义替换（Synonyms / Paraphrasing）

题目与原文经常使用不同表达。

| 题目表达 | 原文可能表达 |
|---|---|
| increase | rise |
| decrease | decline |
| important | significant |
| cause | lead to |
| difficult | challenging |
| buy | purchase |
| development of technology | technological advances |
| reduced the need for | rely less on |
| manual labour | human workers |

不能只依赖原词匹配答案

### 8.3 逻辑理解（Logical Understanding）

理解句子和段落之间的关系：

- Cause and Effect — 因果关系
- Contrast — 对比关系
- Concession — 让步关系
- Example — 举例关系
- Conclusion — 总结关系

### 8.4 篇章理解（Reading for Gist）

理解：

- 段落中心思想
- 作者观点与态度
- 文章结构
- 论证过程

这是 Matching Headings、Matching Information 等题型的重要基础

## 9. 题型与底层能力的关系

| 题型 | 核心能力 |
|---|---|
| Sentence Completion | 定位 + 同义替换 + 词性判断 |
| Table Completion | 定位 + 信息提取 |
| Note Completion | 定位 + 信息归纳 |
| Summary Completion | 段落理解 + 同义替换 |
| Flow-chart Completion | 定位 + 顺序逻辑 |
| Diagram Labeling | 定位 + 空间关系 |
| True / False / Not Given | 定位 + 逻辑判断 |
| Yes / No / Not Given | 定位 + 作者观点 |
| Matching Headings | 段落中心思想 |
| Matching Information | 定位 + 细节理解 |
| Matching Features | 关系匹配 + 定位 |
| Multiple Choice | 细节理解 + 排除干扰 |

学习重点不是记住 14 套互不相关的技巧，而是通过题型训练逐渐掌握共同的阅读能力

## 10. 建议的学习阶段

### 阶段 1：基础定位与信息提取

目标：找得到答案，理解原文

重点练习：

1. Sentence Completion — 句子填空
2. Short Answer Questions — 简答题
3. Table Completion — 表格填空
4. Note Completion — 笔记填空

训练重点：

- 关键词定位
- 同义替换
- 词性判断
- 字数限制
- 精准提取信息

### 阶段 2：信息理解与逻辑判断

目标：理解句子、信息和逻辑关系

重点练习：

5. Summary Completion — 摘要填空
6. Flow-chart Completion — 流程图填空
7. Diagram Labeling — 图表标注
8. Matching Sentence Endings — 句子配对
9. True / False / Not Given — 事实判断
10. Yes / No / Not Given — 观点判断

训练重点：

- 上下文理解
- 信息归纳
- 先后顺序
- 因果、转折等逻辑
- TRUE / FALSE / NOT GIVEN 的区别
- 作者观点识别

### 阶段 3：复杂理解与综合能力

目标：理解段落、作者观点和文章结构

重点练习：

11. Matching Headings — 段落标题匹配
12. Matching Features — 特征匹配
13. Matching Information — 段落信息匹配
14. Multiple Choice — 选择题

训练重点：

- 段落中心思想
- 人物、观点和事实对应
- 全文扫描
- 细节理解
- 排除干扰选项

### 阶段 4：综合实战

- 混合题型训练
- Cambridge IELTS 真题训练
- 60 分钟限时模拟
- 错题分析
- 薄弱点专项突破

## 11. 每种题型的固定学习方法

以后学习每种题型，统一按照以下结构进行：

1. **题型介绍** — 题目长什么样、考试如何考
2. **出题规律** — 常考内容、题目如何设置
3. **解题步骤** — 一套可重复使用的方法
4. **常见陷阱** — 同义替换、干扰信息、逻辑陷阱
5. **专项练习** — 从简单到困难，逐步增加难度
6. **错题复盘** — 分析错误原因，积累同义词和经验

练习时先独立作答，再分析：

- 为什么答案是这个？
- 原文依据在哪里？
- 题目与原文是如何进行同义替换的？
- 其他选项为什么错？
- 这道题暴露了什么问题？

## 12. 题型组合与考试策略

### 组合 A：Sentence Completion + T/F/NG

两种题型通常具有顺序性。可以先建立原文定位区间，再顺着文章向后做，减少重复阅读

### 组合 B：Matching Headings + Matching Information

- Headings：理解段落中心思想
- Information：根据具体信息扫描段落

先理解文章结构，再用题目中的关键词定位细节

### 组合 C：填空 + Multiple Choice

先做容易定位的填空题，帮助建立文章内容和段落位置的认识，再处理选择题

### 组合 D：Matching Features + Matching Information

不要依赖题目顺序。建立人物、观点、事实与段落之间的对应关系，采用扫描和上下文确认的方法

> 这些组合属于做题策略建议，不代表每套考试都会出现固定组合

## 13. 学习时的题型速查

### ORDER — 顺序性较强

- Sentence Completion
- Short Answer Questions
- Matching Sentence Endings
- True / False / Not Given
- Yes / No / Not Given

策略：找到前一题答案后，通常继续向后定位

### NON-ORDER — 乱序

- Matching Headings
- Matching Information
- Matching Features

策略：扫描全文，不能依赖题目顺序

### FLEXIBLE — 灵活处理

- Multiple Choice
- Summary Completion
- Note Completion
- Table Completion
- Flow-chart Completion
- Diagram Labeling

策略：先判断题目结构、原文范围、表格/流程/图示逻辑，再定位和确认

## 14. 备考建议与核心原则

1. 不要一开始就挑战最难的 Matching Headings 和 Matching Information
2. 先建立定位能力和同义替换识别能力
3. 逐步训练逻辑判断，尤其是 TRUE、FALSE、NOT GIVEN 的区别
4. 学习题型时不要只记套路，要理解题目为什么这样出
5. 顺序题利用顺序减少重复扫描；乱序题采用全文扫描策略
6. 答案必须回到原文上下文确认，不依赖常识猜测
7. 练习时记录错误类型：定位错误、同义替换没识别、词汇不懂、逻辑判断错误、粗心或超时
8. 熟悉所有题型后，再进入整套限时训练

## 16. Lesson 1 预告：Sentence Completion

第一课从 **Sentence Completion（句子填空）** 开始

学习内容：

- 题型介绍与出题规律
- 如何提取题目关键词
- 如何定位原文
- 如何识别同义替换
- 如何判断空格词性
- 如何遵守字数限制
- 基础到中等难度专项练习

训练目标：看到题目后，能够快速定位原文、理解题目与原文的替换关系，并准确提取答案

## 总结

雅思阅读不应被理解为 14 种完全独立的题型。它们共同依赖四种核心能力：

**定位能力 → 同义替换 → 逻辑理解 → 篇章理解**

掌握这四项能力，再逐步熟悉各题型的规则，才能从“逐句翻译、全文寻找”转变为更有策略、更高效的阅读
