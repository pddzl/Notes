## 论点内衔接手段

  

| 任务类型 | 逻辑衔接词                                                          | 注意事项                                                                                                      |
| ---- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 解释因果 | **因为**：because, since, as<br>**所以**：so, therefore, as a result | - "因为"和"所以"不能出现在同一个句子中<br>- "because"和"so"尽量不要放在句首，不够书面、正式<br>- 在句首使用"therefore"和"as a result"时，需要在后面加上逗号 |
| 假设   | 如果：if                                                          | 句子时态："主将从现"或者"主情从现"                                                                                       |
| 作对比  | 相反/然而：By contrast, In contrast, Conversely                     | 常常用在句首，后面需要加上逗号                                                                                           |
| 举例子  | 比如：For example, For instance, such as                          | - 只有"For example"和"For instance"能用在句首，用于引出具体实例，后面紧跟完整句子<br>- "such as"只能用在句中，用于列举特定事物，与名词短语连用             |

## 论点间/段落间衔接手段

  

| 位置  | 情况            | 逻辑衔接词                                                                                                                                                           | 注意事项                                                  |
| --- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| 论点间 | /             | **首先**：First, Firstly, First of all, To begin with<br>**其次**：Second, Secondly, Moreover, In addition, Furthermore<br>**最后**：Finally, Lastly, Last but not least | 同时使用 "first"/"firstly"；"second"/"secondly" 时，需要确保前后一致 |
| 段落间 | "观点类"任务：正反面论证 | **然而**：However, Nevertheless, Nonetheless                                                                                                                       | 常常用在句首，后面需要加上逗号                                       |
| 段落间 | "观点类"任务："一边倒" | 直接使用表"首/先/其次"的逻辑衔接词                                                                                                                                             | 参考上方"论点间"的逻辑衔接词                                       |
| 段落间 | 非"观点类"        | 通常不需要用额外的逻辑衔接词                                                                                                                                                  | 见下方"补充：固定句型"                                          |
### 补充：固定句型

- **原因**：（原因 1）and（原因 2）may lead to the problem.

- **措施**：To address this issue, the following measures could be implemented.

- **影响**：Consequently, these causes have given rise to a number of significant effects.

- **观点**：In light of these factors, my view is that ...
