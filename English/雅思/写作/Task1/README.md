## 1. 基础知识

### 1.1. 任务类型

任务类型：图表类写作，根据题目提供的图表或视觉信息进行描述

题型：

1. [[English/雅思/写作/Task1/静态图/README|静态图]]
2. [[English/雅思/写作/Task1/动态图/README|动态图]]
3. [[English/雅思/写作/Task1/流程图/README|流程图]]
4. [[English/雅思/写作/Task1/地图/README|地图]]

### 1.2. 字数、时间与分数占比

- **字数要求：** 至少 150 词，建议约 160–190 词，具体以图表信息量为准
- **时间安排：** 建议约 20 分钟
- **分数占比：** Task 1 通常占写作总分约 1/3，Task 2 占约 2/3

### 1.3. 核心目标

不是逐项抄写图表中的数据，而是：

1. 准确改写题目
2. 概括图表的主要特征
3. 选择关键数据进行描述
4. 对相关数据进行比较
5. 使用准确、自然的语言组织文章

### 1.4. 评分标准

雅思写作主要从以下四个方面评分：

| 评分标准      | 英文名称                           | Task 1 的关注点                |
| --------- | ------------------------------ | -------------------------- |
| 任务完成情况    | Task Achievement               | 是否准确描述主要特征，是否有清晰的 Overview |
| 连贯与衔接     | Coherence and Cohesion         | 段落组织是否合理，信息之间是否衔接自然        |
| 词汇丰富度     | Lexical Resource               | 词汇是否准确、丰富，搭配是否自然           |
| 语法多样性与准确性 | Grammatical Range and Accuracy | 句式是否多样，语法是否准确              |

## 2. 常用结构

通常可以采用四段式：

| 段落  | 名称               | 主要内容         |
| --- | ---------------- | ------------ |
| 第一段 | Introduction     | 改写题干，介绍图表内容  |
| 第二段 | Overview         | 概括主要趋势、特征或变化 |
| 第三段 | Body Paragraph 1 | 描述第一组关键数据或特征 |
| 第四段 | Body Paragraph 2 | 描述第二组关键数据或特征 |

### 2.3. 主体段 Body Paragraphs

核心任务：选择关键数据，进行有逻辑的描述和比较。

常用方法：

- 按时间顺序分组
- 按数据大小分组
- 按相似特征分组
- 按类别分组
- 根据空间位置或流程阶段分组

四段式是常用结构，但不是固定要求。段落划分应服务于图表信息，不要为了凑段落而拆开相关数据

## 3. 推荐学习顺序

### 阶段一：建立基础

1. 熟悉 Task 1 的四段式结构
2. 学会改写题干
3. 掌握 Overview 的写法
4. 学会识别图表的主要特征

### 阶段二：掌握数据图表

1. 动态图：趋势、变化、时态
2. 静态图：极值、比较、分类
3. 表格：筛选关键数据
4. 混合图：综合分析

### 阶段三：专项练习

1. 地图：位置、变化、时态
2. 流程图：步骤、衔接、被动语态
3. 生命周期：生长阶段、变化过程

### 阶段四：整篇写作

每次练习都完成以下步骤：

1. 审题，确定图表类型
2. 找出主要特征
3. 写出 Overview
4. 对数据或步骤进行分组
5. 完成两个主体段
6. 检查时态、语法、词汇和字数
