## 描述具体数据变化的句型

| 句型  | 项目  | 内容                                                                                                                                            |
| --- | --- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 句型1 | 结构  | 数据对象 + 描述变化的动词 + 副词 + 具体数值变化                                                                                                                  |
| 句型1 | 例句  | The number of visitors dropped dramatically from 7.0 million in 2019 to 1.2 million in 2021.；参观者的人数从 2019 年的 7 百万大幅下降到 2021 年的 120 万。         |
| 句型2 | 结构  | There be + (a/an) + 描述变化的形容词 + 名词 + in + 数据对象 + 具体数值变化                                                                                        |
| 句型2 | 例句  | There was a dramatic drop in the number of visitors from 7.0 million in 2019 to 1.2 million in 2021.；参观者的人数从 2019 年的 7 百万大幅下降到 2021 年的 120 万。 |

  

## 描述"数据对象"的常用表达

| 中文含义         | 常用表达                       | 示例                                             |                                                            备注                                                            |
| ------------ | -------------------------- | ---------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------: |
| ……（可数名词）的数量  | the number of ...          | the number of visitors；参观者的数量                  |                                                                                                                          |
| ……（不可数名词）的数量 | the amount of ...          | the amount of funding；资金的数量                    |                                                                                                                          |
| ……的比例/百分比    | the percentage of ...      | the percentage of satisfied visitors；满意参观者的百分比 |                                                                                                                          |
| ……的销售额       | the sales of ...           | the sales of food and souvenirs；食品和纪念品的销售额     | 易混淆的 3 个表达：sales 通常指某个物品的销售量或销售额；price 仅指某个物品价值多少，不能用于描述销售量或销售额；consumption 通常指的是资源（如电力、水、燃料等）或商品（食品、饮料等）的使用量，不能用来描述销售量。 |
| ……的价格        | the price of ...           | the price of an admission ticket；门票的价格         |                                                            同上                                                            |
| ……的消耗量       | the consumption of ...     | the consumption of energy；能源的消耗量               |                                                            同上                                                            |
| ……的温度        | the temperature **in** ... | the temperature in Sydney；悉尼的气温                |                                                   表示"某地"的温度时，要用介词 "in"                                                   |
| ……的数据        | the figure **for** ...     | the figure for industry；行业的数据                  |                                                  最通用的表达，但注意介词一定要用 "for"                                                  |
