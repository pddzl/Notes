## 1. 流程图分类

雅思小作文中的流程图（Process Diagram）主要分为两类：

1. 生产过程（Production Process）：描述原材料经过一系列加工步骤，最终变成产品的过程
2. 生物生命周期（Life Cycle）：描述生物从一个生长阶段到下一个阶段的变化过程，通常具有循环性

按照流程的整体特征，还可以分为：

- 线性流程（Linear Process）：从起点经过多个步骤，最终到达终点
- 循环流程（Cyclical Process）：经过多个阶段后，最终回到起始阶段，形成循环

## 2. 流程图写作结构

流程图作文通常包括四个部分：

1. Introduction（引言段）：改写题目，说明图表展示的流程
2. Overview（概述段）：概括流程的主要阶段、起点、终点及整体特征
3. Body Paragraph 1（主体段 1）：描述前半部分步骤
4. Body Paragraph 2（主体段 2）：描述后半部分步骤

### 2.1 主体段如何分段？

#### 一个流程图

方法一：按照步骤顺序分段

- 主体段 1：步骤 1–3
- 主体段 2：步骤 4–6

方法二：按照步骤特征分段

根据步骤之间的共同特征进行分组。

例如：

- 主体段 1：发生在地下的步骤
- 主体段 2：发生在地面的步骤
#### 多个流程图

可以根据不同图示之间的关系进行分组，同时确保每个图表中的主要信息都得到描述

## 3. Introduction：流程图开头段

### 3.1 基本结构

The diagram + 图表说明词 + 流程描述

常用图表说明词：

|单词|中文含义|
|---|---|
|show|展示|
|illustrate|说明、展示|
|demonstrate|展示、说明|
|depict|描绘|

雅思写作中，`The diagram illustrates ...` 是一种简洁、自然的开头方式

### 3.2 描述做某事的过程

**句型：**

`The diagram illustrates the process of doing sth.`

例句：

`The diagram illustrates the process of producing sugar.`

该图展示了生产糖的过程

### 3.3 描述某物被制作或处理的过程

**句型：**

`The diagram shows the process by which sth. is produced.`

例句：

`The diagram shows the process by which sugar is produced.`

该图展示了糖的生产过程

### 3.4 描述人们完成某事所遵循的流程

**句型：**

`The diagram illustrates the process that people follow in order to do sth.`

例句：

`The diagram illustrates the process that people follow in order to produce sugar.`

该图展示了人们生产糖所遵循的流程

### 3.5 开头句型总结

|描述方式|句型|
|---|---|
|描述做某事的过程|The diagram illustrates the process of doing sth.|
|描述某物被生产的过程|The diagram shows the process by which sth. is produced.|
|描述人们完成某事的流程|The diagram illustrates the process that people follow in order to do sth.|

**记忆重点：**

优先掌握前两种句型即可：

- The diagram illustrates the process of producing sugar.
- The diagram shows the process by which sugar is produced.

## 4. Overview：流程图概述段

### 4.1 需要概括什么？

流程图的 Overview 主要关注以下内容：

1. 流程包含几个主要阶段
2. 流程从哪里开始
3. 流程在哪里结束，或者如何回到起始阶段
4. 流程是线性的还是循环的

不需要在 Overview 中详细描述每一步的具体操作

### 4.2 线性流程（Linear Process）

线性流程从一个起点开始，经过多个步骤，最终到达一个终点

常用句型：

（1）概括主要阶段

`Overall, the process consists of four main stages.`

总体而言，该流程包含四个主要阶段

（2）概括流程的起点和终点

`The process begins with ... and ends with ...`

该流程从...开始，以...结束

（3）概括整个流程

`Overall, the process involves several stages, starting with ... and finishing with ...`

总体而言，该流程包含多个阶段，从...开始，最终以...结束

### 4.3 循环流程（Cyclical Process）

循环流程由多个阶段组成，最后一个阶段会重新连接到起始阶段，形成一个完整的循环。

常见类型：

- 生物生命周期：蝴蝶、青蛙等
- 自然循环：水循环等

与线性流程不同，循环流程通常没有一个永久的终点。

Overview 需要概括：

1. 这是一个循环过程
2. 流程包含哪些主要阶段
3. 流程如何回到起始阶段

常用句型：

（1）说明这是一个循环过程

`Overall, the diagram illustrates a cyclical process.`

总体而言，该图展示了一个循环过程。

（2）概括循环的主要阶段

`Overall, the life cycle consists of four main stages.`

总体而言，该生命周期包含四个主要阶段。

（3）概括整个循环过程

`Overall, the process is cyclical, beginning with ... and eventually returning to this stage.`

总体而言，该过程是循环性的，从...开始，最终又回到这一阶段

## 5. Body：描述流程的具体步骤

主体段按照图示中的实际顺序描述各个步骤。线性流程和循环流程都可以使用以下通用句型

### 5.1 描述流程的开始

（1）The process begins with ...

流程开始于...

例句：

`The process begins with the collection of raw materials.`

该流程从收集原材料开始

（2）The first step involves ...

第一步涉及...

例句：

`The first step involves collecting raw materials.`

第一步涉及收集原材料。

（3）The first step is marked by ...

第一步的特点是...

该表达可以用于强调某个步骤的特征，但通常不如前两种表达直接。

（4）XXX begins life as ...

某种生物最初以...的形态开始生命历程。

例句：

`A butterfly begins life as an egg.`

蝴蝶的生命始于卵

语法重点：

| 句型            | 后面接什么       |
| ------------- | ----------- |
| begin with    | 名词、名词短语或动名词 |
| involve       | 名词、名词短语或动名词 |
| be marked by  | 名词或名词短语     |
| begin life as | 名词或名词短语     |

### 5.2 描述中间步骤

（1）Next / Then / After that, ...

接下来，...

例句：

`Next, the raw materials are transported to the factory.`

接下来，原材料被运送到工厂

（2）This is followed by ...

接下来是...

例句：

`The mixture is heated. This is followed by a cooling stage.`

混合物经过加热，接下来是冷却阶段

语法重点：

`This is followed by ...` 使用被动语态

- `This` 指代前面提到的步骤或过程
- `is followed by` 表示某一步骤之后紧接着发生什么
- `by` 后面通常接名词、名词短语或动名词

（3）The second / third / fourth step is ...

第二步、第三步、第四步是...

例句：

`The second step is to heat the mixture.`

第二步是加热混合物

（4）Once / After / When ...

当...完成之后...

例句：

`Once the powder has been delivered to the mixer, it is transferred to the heater.`

粉末被送入混合器后，会被转移到加热器中

语法重点：

- `Once`: 一旦...; 当...之后
- `After`: 在...之后
- `When`: 当...时
- `has been delivered`: 现在完成时的被动语态
- `is transferred`: 一般现在时的被动语态

这里使用 `Once + 现在完成时`，可以强调前一个步骤完成后，再进行下一个步骤

不过，这不是固定要求。描述流程时，也可以根据具体语境使用一般现在时

### 5.3 描述生物的成长与变化

循环流程中经常需要描述生物从一个阶段发展到另一个阶段。

常用表达：

|表达|中文含义|
|---|---|
|develop into|发育成、发展成|
|transform into|转变成|
|turn into|变成|
|become|变成|

例句：

`The larva develops into a pupa.`

幼虫发育成蛹。

`The pupa then develops into an adult butterfly.`

随后，蛹发育成成年蝴蝶。

### 5.4 描述流程的最后一步

（1）The process ends with ...

该流程以...结束

例句：

`The process ends with the packaging of the finished products.`

该流程以包装成品结束

（2）The final step involves ...

最后一步涉及...

例句：

`The final step involves packaging the finished products.`

最后一步涉及包装成品

（3）Finally, ...

最后...

例句：

`Finally, the finished products are delivered to supermarkets.`

最后，成品被运送到超市

语法总结：

| 表达           | 用法            |
| ------------ | ------------- |
| end with     | 后接名词、名词短语或动名词 |
| involve      | 后接名词、名词短语或动名词 |
| Finally, ... | 后接完整句子        |

`Finally` 主要用于引出最后一个步骤；`Eventually` 更强调经过一段时间或一系列过程后，某事最终发生

在流程图中，描述最后一个步骤时，通常优先使用 `Finally`

### 5.5 循环流程特有的结尾表达

循环流程与线性流程的主要区别在于：最后一个阶段不是一个永久的终点，而是重新连接到起始阶段

因此，在描述循环流程的最后阶段时，可以使用以下表达：

（1）The cycle begins again.

这个循环重新开始。

（2）The process repeats itself.

这个过程再次重复

（3）..., starting the cycle again.

..., 从而重新开启这个循环

例句：

`The adult butterfly lays eggs, starting the cycle again.`

成年蝴蝶产卵，生命周期再次开始。

（4）..., returning to the initial stage.

...，回到最初阶段

例句：

`The water eventually returns to the sea, returning to the initial stage of the cycle.`

水最终回到海洋，重新回到循环的初始阶段

记忆重点：

循环流程主体段结尾优先掌握：

- The cycle begins again.
- The process repeats itself.
- ..., starting the cycle again.

不需要全部记忆，根据图示选择合适的表达即可

## 6. 流程图的时态与语态

### 6.1 时态

| 图示类型      | 常用时态          |
| --------- | ------------- |
| 客观存在的生产流程 | 一般现在时         |
| 生物生命周期    | 一般现在时         |
| 过去发生的特定过程 | 根据题目使用过去时     |
| 未来的特定过程   | 根据题目使用相应的将来表达 |

**记忆重点：**

如果题目描述的是一个客观存在的流程，通常使用一般现在时。

例句：

`The raw materials are transported to the factory.`

原材料被运送到工厂。

### 6.2 语态

如果重点是原材料、产品或生物经历的变化，通常使用被动语态。

主动语态：

`Workers heat the mixture.`

工人加热混合物。

被动语态：

`The mixture is heated.`

混合物被加热。

流程图写作通常更关注每个步骤发生了什么，而不是由谁完成，因此被动语态非常常见。

不过，如果图示明确强调人的操作，或者主动语态表达更自然，也可以使用主动语态。

## 8. 记忆重点

### 8.1 通用写作框架

|写作部分|核心内容|
|---|---|
|Introduction|The diagram illustrates the process of ...|
|Overview|主要阶段 + 流程整体特征|
|Body Paragraph 1|描述前半部分步骤|
|Body Paragraph 2|描述后半部分步骤|

### 8.2 线性流程与循环流程的记忆区别

线性流程（Linear Process）

- Overview：The process begins with ... and ends with ...
- Body：Next ... / This is followed by ...
- 结尾：Finally ... / The process ends with ...

循环流程（Cyclical Process）

- Overview：Overall, the diagram illustrates a cyclical process.
- Body：Next ... / This is followed by ... / ... develops into ...
- 结尾：The cycle begins again. / The process repeats itself.

### 8.3 写作时的四个注意事项

1. 时态：描述客观流程时，通常使用一般现在时
2. 语态：描述原材料或产品的加工步骤时，通常使用被动语态
3. 顺序：按照图中步骤的实际先后顺序描述，不要遗漏关键环节
4. 衔接：合理使用 `Next`、`Then`、`After that` 和 `Finally`，避免每句话都使用相同的连接词

核心思路：

开头说明流程是什么，Overview 概括流程的整体特征，主体段按照实际顺序描述具体步骤

线性流程重点描述从起点到终点的过程；循环流程则需要额外说明最后一个阶段如何重新连接到起始阶段
